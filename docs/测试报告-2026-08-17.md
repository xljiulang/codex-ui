## 五、本轮修复的测试基础设施问题（非应用缺陷）

1. **README `CODEX_BIN='codex'` 指引失效**：PATH 中 `codex` 是 npm 安装的 `.cmd`/`.ps1` shim，Rust `Command::new` 无法直接启动（`program not found`）。修复：`app_server_integration.rs` 增加 shim → 真实 `codex.exe` 解析（npm 嵌套/扁平布局 + 官方安装兜底），README 补充说明；验证 `CODEX_BIN='codex'` 6/6 通过。
2. **`run-e2e.mjs` Windows 下 `spawnSync npm` ENOENT**：npm 同为 `.cmd` shim。修复：改用 `node + npm-cli.js` 启动，codex 版本探测改 `cmd /c`；`--build` 全流程可跑。
3. **E2E 探针过时（三个方向）**：
   - 8/16 `ad7fc6b` 起应用允许零会话标签，启动不再自动建会话 → 新增 `window.__CODEX_UI_TEST__.newSession()` 测试钩子（`boot.ts`，与 `__CODEX_UI_EDITOR__` 同模式），新增 `ensureSession`/`openDiffTab` 共享 helper，7 个探针改用钩子建会话；
   - diff 已从独立窗口改为主窗口内嵌标签（`diff-embedded`）→ `verify-diff`/`verify-mentions` 的 diff 检查改为主页面可见标签断言；
   - 类名变更（`.history-panel`→`.history-view`、`.editor-resize-handle`→`.composer-resize-handle`、CSS 变量 `--editor-h`→`--composer-h`、最低高度 96→120）与多会话标签下 `querySelector(".send-btn")` 命中隐藏旧会话 → 全部改为可见元素/新类名，发送按钮改为轮询可见按钮。
4. **`verify-diff`/`verify-mentions` 漏导入 `sleep`**：补导入（此前一旦走到等待分支即 ReferenceError）。
