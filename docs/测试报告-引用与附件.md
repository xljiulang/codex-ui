## 三、本次修复

1. **【中】`$` 菜单补键盘导航，与 `@` 一致**：`MentionMenu.vue` 的技能列表增加高亮态（hover/↑↓ 同步），`selectHighlighted` 对 `$` 分支选中高亮技能；`ComposerBar.vue` 的 Enter/↑↓ 拦截从仅 `@` 扩展为 `@`/`$` 通用。修复前 Enter 会直接发送原始文本，修复后 Enter 选中技能并生成附件（E2E 断言消息数 1→1、组件测试覆盖 Enter 与 ↑↓ 选中）。
2. **【中】`$` 触发词放开冒号**：`matchMentionToken` 改为按类型校验字符集——`$` 允许冒号（`$ida-pro-mcp:idapython` 可整名触发），`@` 仍不允许（Windows 文件名不含冒号，语义不变）。E2E 实测 22 个插件技能可整名触发。
3. **【低】测试方法学要点（非产品缺陷）**：E2E 启动应用必须可见窗口；`Start-Process -WindowStyle Hidden` / `windowsHide: true` 会阻止 WebView2 初始化，远程调试端口不开放。已在 `verify-mentions.mjs` 中固定为可见启动。

### 保留的设计限制

- 触发词必须是文本末尾的完整 token，输入空格后菜单即关闭：`@my file.txt`（文件名含空格）无法整名触发，需用本地文件选择器。这是 mention 触发语法的既有语义（空格结束触发词），本次不改动。

## 四、已核实的设计行为（非缺陷）

- `@` 必须位于行首或空格后（`看下@file` 不触发），为 `matchMentionToken` 既有设计。
- 发送格式与 `docs/引用与附件.md` 一致：文件段 `# Files mentioned by the user:` + `## My request:` + 技能链接 + 结构化 skill 项；路径统一正斜杠；图片保留为 `localImage` 项。
- 同一条消息含结构化 skill 项时，文本技能链接不重复渲染（去重生效）。
- `@` 空 token 时 Enter 打开本地文件选择器（组件测试覆盖）。
