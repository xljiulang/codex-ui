# codex-ui 前端模块地图

> Vue 3 + TypeScript + Tauri 桌面应用。`src/` 为前端，`src-tauri/` 为 Rust 后端。
> 修改功能时，通常联动「界面组件 + 对应 composable + 可能的后端命令」。

## Windows 路径约定（新增功能必读）

- 外部传入的绝对路径可能带正斜杠（git CLI 输出）或反斜杠、大小写任意，一律接受；
  组件内部用正用反是自身的事，但**比较（相等/包含/相对化）必须走 `src/lib/path.ts` 的全局共享方法**
  （`pathEquals` / `isPathUnderRoot` / `relPathOf`，基于 `normalizePathKey`），禁止散落各自的 replace/compare。
- 路径用作 Map/Set 键（资源树 `childrenByPath`/`expanded`、历史分组 key 等）时必须先经
  `normalizeFsPath` / `normalizePathKey`，保证同一逻辑路径不会因分隔符/大小写产生多个键。
- 后端 `path_util::clean_path` 保证对外绝对路径统一反斜杠；相对路径（git 文件路径、`relPath` 展示）内部保持正斜杠，
  比较同样走共享方法。
- `links.ts` / `pdfExport.ts` 里为 `file://` URL 转正斜杠属于「转换」而非「比较」，不受上述约束。

## 多会话状态隔离约定（新增功能必读）

- 会话标签相互独立：**以标签为单位的操作（发送/关闭/停止/事件路由）只读写目标标签（`tab.*`），不经过全局 `store.*`**。
- `store.*` 仅作为「活动标签」的 live 投影（切换标签时由 `restoreSession`/`syncActiveSessionTab` 同步），带线程身份的后台路径一律不得读写它。
- 典型反例与正确做法：`interrupt(threadId, turnId)` 显式线程路径不得回退 `store.currentTurnId`；后台发送（`continueTurnForTab`）的任务模式取 `tab.taskMode` 而非 `store.taskMode`；回合事件按 `p.threadId` 归属到标签后只写该标签。

## 查找规律

改某个功能时，通常 = **界面组件 + 对应 composable + 可能的后端命令**。例如：
