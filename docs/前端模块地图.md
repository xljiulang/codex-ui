# codex-ui 前端模块地图

> Vue 3 + TypeScript + Tauri 桌面应用。`src/` 为前端，`src-tauri/` 为 Rust 后端。
> 修改功能时，通常联动「界面组件 + 对应 composable + 可能的后端命令」。

## 顶层布局与框架

| 文件 | 功能 |
|---|---|
| [App.vue](../src/App.vue) | 根组件：组装顶栏、编辑区、右栏、各类弹窗；启动初始化、窗口关闭守卫、全局右键菜单 |
| [AppHeader.vue](../src/components/AppHeader.vue) | 顶栏：新建会话（选目录）、设置开关、会话路径/状态显示 |
| [EditorPane.vue](../src/components/EditorPane.vue) | 主编辑区：标签页框架（文件/DIFF/预览/终端），懒加载重组件，标签关闭/保存/右键菜单 |
| [RightPanel.vue](../src/components/RightPanel.vue) | 右侧面板：资源/历史/Git 三个 Tab 切换、面板宽度拖拽 |

## 聊天界面

| [ReasoningBlock.vue](../src/components/ReasoningBlock.vue) | 推理过程折叠块：流式内容、耗时显示 |

## 查找规律

改某个功能时，通常 = **界面组件 + 对应 composable + 可能的后端命令**。例如：

- 改输入框的 @ 菜单 → `ComposerBar.vue` + `MentionMenu.vue` + `lib/mention.ts`
- 改文件树右键菜单 → `ResourceView.vue` + `useSessionFs.ts`
- 改 Git 提交逻辑 → `GitView.vue` + `useGitChanges.ts` + `src-tauri/.../git.rs`
- 改消息流渲染 → `ChatView.vue` + `MessageItem.vue` + `MarkdownText.vue`

另见 [变更记录.md](./变更记录.md) 记录历史变更，`scripts/verify-*.mjs` 为 UI 验证脚本，改完交互功能后可跑对应脚本回归。
