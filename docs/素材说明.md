# 素材与参考说明

本目录整理了开发 codex-ui 过程中使用的原始素材（用户提供的截图与图标），均为原始文件，未做修改。

## 素材清单

| 文件 | 内容与用途 |
| --- | --- |
| `ui 参考.png` | 主 UI 参考图（VS Code Codex 插件界面截图）。指导整体布局：底部通栏输入框 + 悬浮按钮、历史列表、消息流、模式按钮、发送按钮。 |
| `加号菜单.png` | “添加内容（+）”菜单参考图（历史素材）。`+` 菜单已于 2026-08-10 移除，功能并入 `@` 触发菜单。 |
| `权限模式菜单.png` | 权限模式菜单参考图（请求批准 / 帮我批准 / 完全访问权限）。指导权限菜单的选项、副标题与勾选态样式。 |
| `发送者的信息重复.png` | 问题复现截图：用户消息（发送者信息）重复显示。用于定位并修复消息去重逻辑。 |
| `app-icon.png` | 应用图标素材。 |

## 与实现的对应关系

- **输入区布局**：`ui 参考.png` 中“输入框占满底栏、按钮悬浮在输入框之上且靠底对齐”的布局，对应 `src/components/ComposerBar.vue` 与 `src/style.css` 中 `.composer`、`.composer-left`、`.composer-right` 的实现。
- **权限菜单**：`权限模式菜单.png` 对应 `src/components/PermissionMenu.vue`（三种模式、副标题、勾选态），以及 `src/lib/permissions.ts` 中的模式映射。
- **加号菜单（已移除）**：`加号菜单.png` 曾对应 `src/components/PlusMenu.vue`（文件和文件夹、插件/技能）；现已删除，文件和插件统一由 `@` 触发菜单（`src/components/MentionMenu.vue`）选择。
- **消息去重**：`发送者的信息重复.png` 对应 `src/composables/useCodex.ts` 中 `upsertItem` 通过 `clientId` 将服务端推送的用户消息与本地乐观插入关联去重的逻辑。
