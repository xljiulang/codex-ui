# codex-ui 变更记录

按日期倒序记录功能与修复，便于回溯每次改动对应的行为与提交。

## 2026-08-11（晚）

### 置顶兼容三代 codex 协议（`0bf307e`）

- 置顶不再依赖单一协议：首次点击置顶时自动探测能力（`threadSection/list` 存在分区后依次探测 `threadSection/move`、`metadata/update { sectionId }`；无分区则探测 `metadata/update { isPinned }`），覆盖 `0.146.0-alpha.9.2` 至 `v0.147.0+` 三代 codex。
- 修复旧版 `thread/metadata/update` 报 “thread metadata update must include at least one field” 的问题。

### 历史会话按目录分组（`56f11dc`）

- 历史列表按会话所属目录归入同名文件夹，文件夹默认收起；只有单条会话的目录不建夹。
- 历史记录不再显示路径文本（目录信息已体现在文件夹上）。

### 设置改为模态对话框（`b570e33`）

- 设置由左侧面板改为模态对话框；新增“取消保存”按钮，“保存设置”改名为“保存”。
- 点“保存”后关闭对话框；新建对话后输入框自动获得焦点。

### 输入区拖放与会话切换交互（`47a62a5`）

- 输入富文本框支持文件拖放添加附件，逻辑与 Ctrl+V 一致。
- 会话进行中触发“新建对话”或“切换到其它历史会话”时弹出确认框（停止并切换 / 取消）。
- 头部按钮状态调整：仅“历史记录”按钮有 active 状态且独立，不受新建/设置按钮影响；新建、设置不再有选中态。
- 修正历史列表“加载更多”字体与其它区域不一致的问题。

### 点击当前会话不重载（`d1cb4f4`）

- 历史列表中点击当前正在进行的会话不再重载、不重置运行状态，避免“停止”按钮被误置为结束状态。

### 主题切换保存后生效（`fbcd8ea`）

- 设置页点击主题卡片仅更新选中态，点“保存”才写入并应用；取消/重开对话框恢复原主题。

### 仿 VS Code 自动生成会话标题（`47e3ab2`、`af985b7`）

- 新会话首条消息（去掉文件引用后的纯文本 > 15 字）发出后，后台用临时线程 + 默认模型总结首条消息生成短标题，并通过 `thread/name/set` 写回；与主回合并行执行，失败静默保留原标题。
- 兼容矩阵：支持 `experimentalApi` + `ephemeral` 用内存临时线程；支持 `experimentalApi` 但不支持 `ephemeral` 用普通线程总结后删除；不支持 `experimentalApi` 完全跳过标题总结。
- 新增能力探测 `codex_title_helper_capability`（创建内存线程后立即释放，只读）；临时线程事件与主对话全局状态隔离（不误改进行中状态）。
- 协议参数修复：`thread/start` 的 `sandbox` 使用 kebab-case `"read-only"`，`turn/start` 使用 `sandboxPolicy` 对象（`{ type: "readOnly", networkAccess: false }`）。

### 测试与验证

- vitest 全量 279 例通过（含标题总结能力/触发/隔离用例）、vue-tsc 通过、`npm run build` 成功、release 编译通过。
