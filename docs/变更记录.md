# codex-ui 变更记录

按日期倒序记录功能与修复，便于回溯每次改动对应的行为与提交。

## 2026-08-12（下午）

### 三主题样式审计落地（`e2d860e`）

基于对蓝夜/曜黑/晨光三套主题的取证审计（真实应用 CDP 截图 + 运行时令牌对比度计算），落地以下改良：

- **对比度达标（WCAG AA 基线）**：
  - 主按钮白字：三主题渐变浅端加深——蓝夜/晨光 `#2563eb→#1d5fc4`、曜黑 `#7557ec→#6d54e8`，白字对比度由 2.56–3.87 提升到 ≥4.85。
  - `--text-faint` 全部提升到 ≥4.5:1（蓝夜 `#76819a`、曜黑 `#868399`、晨光 `#5f6b7a`），覆盖历史时间、工具元信息、推理耗时等 11px 小字。
  - 晨光次级文字：`--text-dim`→`#626e7d`（4.80:1）、`--green`→`#0e7a58`（4.93:1）、`--red`→`#c23a45`（4.87:1）。
- **晨光统一深色终端**：`--console-*` 由浅色改回深色，命令输出/工具卡片/diff 与代码块保持同一“终端”语言；diff 增删文字改浅色（`#9fe3d4`/`#f0a0a0`），diff 窗口内容区转深色容器，行号/分隔/强调行补浅色覆盖，移除原“晨光浅色 diff 高亮”整块；`.md pre` 硬编码深色背景提取为共享令牌 `--code-bg`。
- **主题卡片选中态**：在柔和光环外加 1px 实色 accent 描边，浅色主题下识别更清楚。
- **设置弹窗主题即时预览**：点击主题卡片立即预览到根节点（不写入 localStorage），取消/关闭/Escape 自动还原，保存后保留；新增 `previewTheme()`。
- **取证脚本**：新增 `scripts/audit-themes.mjs`（CDP 三主题截图 + DOM/令牌证据，`--phase static|chat|diff`，可复跑）。
- **验证**：vitest 331/331、vue-tsc、`npm run build`、release 编译通过；重打包后真实回合取证确认晨光控制台/diff 转深色、按钮渐变生效、代码块保持深色。

### 对话 UI 视觉与信息层次改进

- **回合分组**：消息流按 `userMessage` 为边界分成回合（`src/lib/turns.ts` 新增 `createTurnsBuilder`/`buildTurns` 纯函数，行对象按 key 缓存复用）；首个用户消息之前的条目归入历史续接伪回合；组内间距统一为 flex gap，组间 24px 留白，长对话更易扫读。
- **助手最终答复卡片**：`agentMessage` 且 `phase=final_answer` 非流式时，正文包一层 `.agent-final`（圆角、左侧强调条、与工具卡同语言）；commentary 与 plan 保持平铺渲染。
- **用户消息时间戳**：用户气泡现在也显示 HH:mm 时间戳，与助手答复一致。
- **思考块折叠预览**：完成折叠时显示首行内容单行预览，点击预览即展开；流式期间仍默认展开、内容不限高。
- **一致性**：移除工具卡 `tool-card--minimal` 特例，命令/文件变更卡与其它工具卡统一带边框样式；消息操作按钮支持 `:focus-within` 显示，键盘 Tab 聚焦复制按钮时可见。

## 2026-08-12（上午）

### 修复正文总结阶段吸底滚动失效（工具/思考完成之后）

- 解除吸底改为“向上位移 + 距底阈值”判定：可信滚动相对吸底基线向上移动（2px 防抖）且距底部超过 32px 才解除；单次滚轮一次生效，轻微误触/抖动不会在流式期间误解除；程序化滚动与追赶窗口内的向下滚动不误判。
- 解除吸底后不再因内容增长自动回拉，尊重用户阅读位置；恢复吸底仅需滚回距底部 60px 内或点击“回到底部”。
- DOM 结构变化（worker 渲染落地）时在 MutationObserver 微任务内立即吸底，不再等下一帧 rAF；rAF 保留用于高频变更合并，并在次帧再跟一次，兜底 `content-visibility` 解除跳过渲染后的高度变化。
- 懒加载/异步图片加载后的高度变化（无 DOM 结构变更）补 `load` 监听跟随。
- MarkdownText 增量渲染改为缓存顶层节点 HTML（避免每 tick 整段重新 parse + 字符串化）；流式期间代码块暂不高亮（避免增长中的代码块每 tick 全量重高亮 O(n²)），结束后一次性补齐语法高亮。
- 切换会话（新建对话/打开历史/会话失效重置）时重置吸底状态，避免旧会话上滑状态残留导致新对话默认不吸底。

## 2026-08-11（晚）

### 置顶兼容三代 codex 协议（`0bf307e`）

- 置顶不再依赖单一协议：首次点击置顶时自动探测能力（`threadSection/list` 存在分区后依次探测 `threadSection/move`、`metadata/update { sectionId }`；无分区则探测 `metadata/update { isPinned }`），覆盖 `0.146.0-alpha.9.2` 至 `v0.147.0+` 三代 codex。
- 修复旧版 `thread/metadata/update` 报 “thread metadata update must include at least one field” 的问题。

### 历史会话按目录分组（`56f11dc`）

- 历史列表按会话所属目录归入同名文件夹，文件夹默认收起；只有单条会话的目录不建夹。
- 历史记录不再显示路径文本（目录信息已体现在文件夹上）。

### 设置改为模态对话框（`b570e33`）

- 设置由左侧面板改为模态对话框；新增“取消保存”按钮，“保存设置”改名为“保存”。
- 点“保存”后关闭对话框；新建对话后输入框自动获得焦点。

### 输入区拖放与会话切换交互（`47a62a5`）

- 输入富文本框支持文件拖放添加附件，逻辑与 Ctrl+V 一致。
- 会话进行中触发“新建对话”或“切换到其它历史会话”时弹出确认框（停止并切换 / 取消）。
- 头部按钮状态调整：仅“历史记录”按钮有 active 状态且独立，不受新建/设置按钮影响；新建、设置不再有选中态。
- 修正历史列表“加载更多”字体与其它区域不一致的问题。

### 点击当前会话不重载（`d1cb4f4`）

- 历史列表中点击当前正在进行的会话不再重载、不重置运行状态，避免“停止”按钮被误置为结束状态。

### 主题切换保存后生效（`fbcd8ea`）

- 设置页点击主题卡片仅更新选中态，点“保存”才写入并应用；取消/重开对话框恢复原主题。

### 仿 VS Code 自动生成会话标题（`47e3ab2`、`af985b7`）

- 新会话首条消息（去掉文件引用后的纯文本 > 15 字）发出后，后台用临时线程 + 默认模型总结首条消息生成短标题，并通过 `thread/name/set` 写回；与主回合并行执行，失败静默保留原标题。
- 兼容矩阵：支持 `experimentalApi` + `ephemeral` 用内存临时线程；支持 `experimentalApi` 但不支持 `ephemeral` 用普通线程总结后删除；不支持 `experimentalApi` 完全跳过标题总结。
- 新增能力探测 `codex_title_helper_capability`（创建内存线程后立即释放，只读）；临时线程事件与主对话全局状态隔离（不误改进行中状态）。
- 协议参数修复：`thread/start` 的 `sandbox` 使用 kebab-case `"read-only"`，`turn/start` 使用 `sandboxPolicy` 对象（`{ type: "readOnly", networkAccess: false }`）。
