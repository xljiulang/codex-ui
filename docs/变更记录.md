# codex-ui 变更记录

按日期倒序记录功能与修复，便于回溯每次改动对应的行为与提交。

## 2026-08-13（忽略 node_modules 与右键菜单修复）

### 会话资源与 Git 更改无条件忽略 node_modules

- 会话资源（`session_fs.rs`）：列表、搜索（遍历与命中）、目录子项计数与 watcher 事件过滤统一加入 `node_modules`（任意深度、大小写不敏感），与点目录同等隐藏，避免 node_modules 刷屏与变化触发刷新。
- Git 更改（`git.rs`）：status 结果无条件过滤含 `node_modules` 组件的路径（即使文件已被跟踪也隐藏）；watcher 回调同样排除 `node_modules`，其变动不再触发自动刷新。

### 右键菜单不再被外部滚动误关

- `HistoryView` / `ResourceView` 的 window 捕获阶段 scroll 监听收窄为“仅当滚动目标在面板自身（`.history-view` / `.resource-view`）内”才关闭菜单；会话进行中聊天区吸底滚动（工具调用/思考完成触发）不再让右键菜单消失。
- 点击外部、Escape、面板自身滚动关闭菜单的行为保持不变；新增对应 Vitest 用例。

## 2026-08-13（Git 更改状态图标）

### 文件状态改为图标显示

- Git 更改文件行由文字徽标改为 Material 圆形符号图标：新增=加号圆、修改=铅笔、删除=减号圆、未跟踪=问号圆（重命名/冲突保留防御性映射），沿用绿/黄/红状态配色。
- 图标仅作视觉表示，语义文字通过悬停 `title` 提示（新增/修改/删除/未跟踪）；路径文本与点击打开 diff 行为不变。
- `GitView.spec.ts` 断言由状态文字改为图标类名 + `title`。

## 2026-08-13（Git 更改全面切回 gix）

### 零系统 git 依赖

- “Git 更改”后端由系统 git CLI 全面改为内置 **gix 0.86**（纯 Rust）：状态/diff/初始化/忽略规则全部进程内完成，不再 spawn 任何 git 进程，彻底消除黑窗体、git 未安装空状态与反复拉起 git 的开销。
- `git_changes_status`：`gix::discover` 发现仓库；`Repository::status` 产出 HEAD→索引与索引→工作区条目并同路径合并（deleted > added > modified > untracked；冲突按 modified 简化展示）；关闭重命名检测（重命名显示为删除 + 新增两条）。
- `git_changes_init`：仅 `gix::init`（默认分支 main），不自动提交、HEAD 未出生。
- `git_changes_diff`：统一对比 HEAD（暂存 + 未暂存合并，HEAD 未出生视为空），gix 渲染 unified diff；二进制文件返回错误提示；无内容变化返回空串。
- 监听回调除排除点目录（.git 除外）外，新增 gix 排除栈应用 `.gitignore` 规则（已跟踪文件经索引回退放行，`.git` 内部事件始终放行）。
- 前端移除 `no_git` / `git_not_found` 空状态；保留刷新互斥、1s 事件冷却与 init 成功后重建监听。
- 环境要求移除 `git` 依赖项；Rust 测试保留系统 git 仅作搭建仓库的测试夹具（无 git 时跳过）。

### 修复正文总结阶段吸底滚动失效（工具/思考完成之后）

- 解除吸底改为“向上位移 + 距底阈值”判定：可信滚动相对吸底基线向上移动（2px 防抖）且距底部超过 32px 才解除；单次滚轮一次生效，轻微误触/抖动不会在流式期间误解除；程序化滚动与追赶窗口内的向下滚动不误判。

- 懒加载/异步图片加载后的高度变化（无 DOM 结构变更）补 `load` 监听跟随。
- MarkdownText 增量渲染改为缓存顶层节点 HTML（避免每 tick 整段重新 parse + 字符串化）；流式期间代码块暂不高亮（避免增长中的代码块每 tick 全量重高亮 O(n²)），结束后一次性补齐语法高亮。
