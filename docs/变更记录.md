## 2026-08-14（修复终端首次打开空白——事件订阅竞态）

### 原因

- `openTerminalTab` 创建标签后立即调用 `terminal_spawn`，后端 reader 线程随即开始 emit `terminal/output`；而前端订阅事件的代码在懒加载的 `TerminalPane.vue` 挂载后才执行（第一次打开还要等 xterm chunk 加载，gap 最大），Tauri 事件不缓存，gap 期间输出全部丢失。
- 尤其关键的是 ConPTY 启动时的 `CSI 6 n` 光标位置查询：PowerShell 要等终端应答才渲染提示符，查询在 xterm 创建前到达则无人应答，提示符永不显示，表现为“标签能打开但空白黑屏”。
- 次要竞态：挂载时的 `terminal_resize` 可能早于 spawn 完成，被后端“终端不存在”拒绝后静默吞掉，PTY 停在默认 30×100。

### 改动

- 新增 `useTerminalEvents`（单例事件桥）：`ensureTerminalListeners` 幂等注册 `terminal/output`/`terminal/exit` 全局监听（应用生命周期常驻）；无活跃订阅者时按 id 缓冲输出与退出码，`attachTerminal(id)` 返回 `flush()`（回放缓冲）、`exitCode`、`onData`/`onExit` 实时回调与 `detach()`；`releaseTerminal(id)` 在标签关闭时清空缓冲。
- `openTerminalTab` 在 `terminal_spawn` 之前先 `await ensureTerminalListeners()` 并 `attachTerminal(id)`，保证缓冲起点先于后端输出；`removeTab` 对终端标签调用 `releaseTerminal(id)`。
- `TerminalPane` 移除组件内 `listen` 订阅，改经事件桥：挂载后先 `flush()` 回放缓冲（xterm 会对缓冲里的 DSR 自动应答，提示符恢复正常渲染）再转实时；缓冲退出码直接置 `tab.exited`。新增 `watch(tab.loading)`，spawn 完成后补一次 `fit()` + `syncSize()`。
- 后端 ConPTY 协议与实现不变。

### 验证

- 新增 `useTerminalEvents` 单测 7 例（监听单次注册、缓冲/回放、实时分发不重复、退出码两种时序、detach、release、多 id 隔离）。
- `TerminalPane` 新增缓冲回放、缓冲退出码、spawn 完成后二次 resize 3 例并适配事件桥 mock；`useEditorTabs` 新增 spawn 前先建监听/缓冲、关闭释放缓冲 2 例。

## 2026-08-12（上午）

### 修复正文总结阶段吸底滚动失效（工具/思考完成之后）

- 解除吸底改为“向上位移 + 距底阈值”判定：可信滚动相对吸底基线向上移动（2px 防抖）且距底部超过 32px 才解除；单次滚轮一次生效，轻微误触/抖动不会在流式期间误解除；程序化滚动与追赶窗口内的向下滚动不误判。
- 解除吸底后不再因内容增长自动回拉，尊重用户阅读位置；恢复吸底仅需滚回距底部 60px 内或点击“回到底部”。
- DOM 结构变化（worker 渲染落地）时在 MutationObserver 微任务内立即吸底，不再等下一帧 rAF；rAF 保留用于高频变更合并，并在次帧再跟一次，兜底 `content-visibility` 解除跳过渲染后的高度变化。
- 懒加载/异步图片加载后的高度变化（无 DOM 结构变更）补 `load` 监听跟随。
- MarkdownText 增量渲染改为缓存顶层节点 HTML（避免每 tick 整段重新 parse + 字符串化）；流式期间代码块暂不高亮（避免增长中的代码块每 tick 全量重高亮 O(n²)），结束后一次性补齐语法高亮。
- 切换会话（新建对话/打开历史/会话失效重置）时重置吸底状态，避免旧会话上滑状态残留导致新对话默认不吸底。
