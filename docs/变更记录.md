# codex-ui 变更记录

按日期倒序记录功能与修复，便于回溯每次改动对应的行为与提交。

## 2026-08-14（特殊文件打开逻辑扩展：PDF / 图像预览标签）

### PDF 预览

- 资源管理器打开 `.pdf` 文件（右键「打开」/ 文件行单击 / 搜索结果单击）不再提示“无法打开”，改为在主窗口左侧标签区打开 PDF 预览标签：新增后端命令 `session_fs_read_bytes`（路径包含校验、仅文件、50 MiB 上限、base64 返回），前端解码为字节后交给 pdf.js（v6，按需加载）渲染当前页 canvas。
- 预览标签工具栏支持上一页/下一页、页码显示、缩放（默认适应宽度，0.25–4 倍）与“适应宽度”复位；切换标签/卸载时销毁 pdf.js 文档对象；损坏或超限文件在标签内显示错误提示。

### 图像预览

- 打开图像文件（png/jpg/jpeg/gif/webp/bmp/svg/ico/avif，大小写不敏感）直接进入图像预览标签：经 Tauri asset 协议（`convertFileSrc`）加载原图，contain 适配可滚动，加载失败显示占位错误；复用既有 `assetProtocol` 与 CSP `img-src asset:`，无需新增配置。

### 标签系统扩展

- `useEditorTabs` 新增 `preview` 标签类型（`PreviewEditorTab`，`previewType: "pdf" | "image"`）与 `openPreviewTab`：重复打开去重激活、关闭无需脏确认；`EditorPane` 标签栏显示「预览」徽标，图标与悬停提示与文件标签一致。
- 打开逻辑统一在 `requestOpen` 按扩展名分发（`lib/preview.ts` 的 `previewTypeForName`），非特殊类型维持原文本探测 → 文本编辑器 / “无法打开”提示。
- 新增组件 `PreviewPane.vue`（头栏 + 加载/错误态 + 类型分发）与 `PdfPreviewPane.vue`（pdf.js 渲染）；新增 `pdfjs-dist` 依赖，pdf.js 与 worker 按需分包，主包体不受影响。

### 修复正文总结阶段吸底滚动失效（工具/思考完成之后）

- 解除吸底改为“向上位移 + 距底阈值”判定：可信滚动相对吸底基线向上移动（2px 防抖）且距底部超过 32px 才解除；单次滚轮一次生效，轻微误触/抖动不会在流式期间误解除；程序化滚动与追赶窗口内的向下滚动不误判。

- 懒加载/异步图片加载后的高度变化（无 DOM 结构变更）补 `load` 监听跟随。

- 切换会话（新建对话/打开历史/会话失效重置）时重置吸底状态，避免旧会话上滑状态残留导致新对话默认不吸底。
