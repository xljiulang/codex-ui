## 二、已修复缺陷（3 项）

### 1. 【高】调整方向（turn/steer）间歇性失败 — 已修复

- **复现**：跟进处理方式 = 调整方向，回合刚开始（约 150–400ms 内）发送第二条消息 → toast `no active turn to steer`；转向消息上屏但服务端拒绝，最终回复不包含新指示。
- **根因**：`turn/start` 响应先返回（UI 立刻显示“进行中”），但服务端要等 `turn/started` 事件后才把回合标记为“可转向”，存在约 200–500ms 窗口；前端 `steerTurn` 没有重试（对比 `interrupt` 已有 “no active turn” 重试）。
- **修复**：`src/composables/useCodex.ts` 的 `steerTurn` 对 `no active turn` 重试 5 次 × 400ms。
- **验证**：修复前 150ms 延迟必现失败；修复后 6/6 成功（服务端日志可见重试后成功，回复均含“调整已生效”）。

### 2. 【中】命令执行等工具完成后不显示“耗时” — 已修复

- **复现**：执行命令工具完成后，卡片状态只有“成功”，无“耗时 X”（进行中时倒计时正常）。
- **根因**：`item/completed` 处理只对 `reasoning` 计算 `durationMs`，且显式 `durationMs: undefined` 会覆盖服务端 payload 中已有的值。
- **修复**：优先采用服务端耗时；缺失时用 `startedAtMs→completedAtMs` 推算，覆盖命令执行/文件变更等所有工具类型，且不再覆盖已有值。
- **验证**：命令完成后显示“成功耗时 0.8s”。

### 3. 【中】Rust 集成测试无法编译 — 已修复

- **现象**：`cargo test` 编译失败，`settings_roundtrip` 仍断言已删除的 `permission_mode` 字段。
- **修复**：`src-tauri/tests/app_server_integration.rs` 更新为当前 4 项设置（codex_path / sound_enabled / enter_to_send / followup_mode）。
- **验证**：`cargo test` 2/2 通过。

## 三、遗留低优先级问题（未修复，建议后续）

### 4. 【中】窄窗口（400px 最小宽度）输入区按钮组重叠

- **现象**：视口 400px 时，左侧按钮组（+、权限、任务）右缘到 x=197，右侧按钮组（模型、发送）左缘从 x=114 起，重叠区约 114–197，按钮可能互相遮挡。
- **证据**：`narrow-400.png` 截图 + DOM 几何测量（leftRightOverlap=true）。
- **建议**：该宽度下按钮组换行，或收紧间距/字号。

### 5. 【低】运行中工具卡状态文本重复

- **现象**：命令运行中显示“进行中进行中 · 00:00.5”（statusLabel 与 timeLabel 都含“进行中”）。
- **建议**：运行中只显示一个“进行中 · 用时”。

### 6. 【低】模型错误提示为原始 JSON

- **现象**：切到 `deepseek-v4-pro` 后回合失败，toast 显示完整 `{"error":{"message":...}}` 原始 JSON；且上游 `model/list` 返回该模型但 API 尚未开放（“Codex integration with deepseek-v4-pro will be available starting early August 2026”），属上游数据不一致。
- **建议**：toast 解析并展示 `error.message`；模型列表可过滤/标注不可用模型。

### 7. 【低】队列模式下第二条消息发出前无提示

- **现象**：跟进处理 = 加入队列时，回合中发送的消息不可见，直到回合结束自动续发。
- **建议**：入队时显示“已加入队列”提示或队列徽标。

## 四、已核实的设计行为（非缺陷）

- 请求批准模式下，写入 `%TEMP%` 的文件操作不弹审批（tmpdir 在沙箱中默认可写，协议设计）。
- `thread/list` 不显示子代理会话（`source=subagent`），磁盘会话数多于列表数属正常。
- 单独 `thread/start` 不落盘，首条消息发送后才持久化。
- “批准并记住此规则”写入 `~/.codex/rules/default.rules`（非 exec_policy.json），命令真实执行——之前“好像被拒绝”的疑虑排除。
- 会话文件模型字段：切换模型后下一回合使用新模型；`deepseek-v4-pro` 被上游拒绝属上游限制。
